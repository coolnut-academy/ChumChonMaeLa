# คู่มือการติดตั้งและใช้งานระบบเว็บไซต์ โรงเรียนชุมชนแม่ลาศึกษา
**(GitHub Pages + Google Sheets Database + Google Drive Storage)**

ระบบนี้ออกแบบมาเฉพาะสำหรับ **โรงเรียนชุมชนแม่ลาศึกษา** (โทนสีแดง-ขาว, เปิดสอนระดับชั้นอนุบาล 2 ถึง มัธยมศึกษาปีที่ 3 - โรงเรียนขยายโอกาสทางการศึกษา) โดยใช้สถาปัตยกรรม **Single-Page Application (`index.html`)** ที่ทำงานได้ทันทีทั้งในโหมดจำลองข้อมูล และโหมดเชื่อมต่อฐานข้อมูลจริงบน Google Cloud ฟรี 100%

---

## รายการไฟล์ในชุดติดตั้งนี้ (ZIP Package)

1. **`index.html`** — ไฟล์เว็บไซต์หลัก ประกอบด้วยหน้าหลัก หน้าย่อยครบทุกหมวด (เกี่ยวกับโรงเรียน, หลักสูตร 3 ระดับชั้น อ.2–ม.3, ทำเนียบบุคลากร, ข่าวสาร/รางวัล, การรับสมัครนักเรียน, บริการออนไลน์, ข้อมูลความโปร่งใส ITA O1–O43, ติดต่อเรา) และ **ระบบหลังบ้าน (`#/admin`)** โหลดตัวช่วยภาพสำรองจาก `image-placeholders.js` ระบบสไลด์จาก `hero-slideshow.js` ภาพ AI ภายใน `public/images/placeholders/` และโลโก้/ไอคอนภายใน `public/images/branding/` พร้อม `site.webmanifest` จึงต้องนำไฟล์เหล่านี้ขึ้น hosting พร้อมกัน
2. **`Code.gs`** — โค้ด Google Apps Script สำหรับเชื่อมต่อ Google Sheets (ฐานข้อมูล 8 ตาราง) และ Google Drive (คลังเก็บภาพและไฟล์ PDF 5 โฟลเดอร์) พร้อมระบบ `CacheService` ป้องกันโควตาเต็ม
3. **`appsscript.json`** — ไฟล์ตั้งค่าสิทธิ์ของ Google Apps Script
4. **`database_templates/*.csv`** — ไฟล์ตารางฐานข้อมูลเริ่มต้นทั้ง 8 แท็บ (กรณีต้องการนำเข้าผ่านเมนู File > Import ใน Google Sheets ด้วยตนเอง)

## ขั้นตอนที่ 1: ตั้งค่าฐานข้อมูล Google Sheets และคลังไฟล์ Google Drive (ใช้เวลาประมาณ 3 นาที)

1. เข้าไปที่ Google Sheets ฐานข้อมูลของโรงเรียน: [เปิด Google Sheets ฐานข้อมูลโรงเรียนชุมชนแม่ลาศึกษา](https://docs.google.com/spreadsheets/d/1xq7ZoNo3pTSqdyFMfz75Lpzfy4fpqjJOEEUNXtI45B4/edit?gid=0#gid=0)
2. ที่แถบเมนูด้านบน คลิกที่ **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ด `function myFunction() {}` เดิมออกทั้งหมด แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ **`Code.gs`** ไปวางแทนที่ จากนั้นกดไอคอนแผ่นดิสก์ (**บันทึก / Save**)
4. ที่แถบเครื่องมือด้านบนของหน้า Apps Script ให้เลือกฟังก์ชัน **`setupDatabaseAndDrive`** จากเมนูแบบเลื่อนลง แล้วกดปุ่ม **เรียกใช้ (Run)**
5. ระบบจะขอสิทธิ์การเข้าถึง Google Sheets และ Google Drive ของโรงเรียน ให้กด **Review permissions > เลือกบัญชีโรงเรียน > Advanced > Go to project (unsafe) > Allow**
6. เมื่อรันเสร็จสิ้น สคริปต์จะดำเนินการให้อัตโนมัติ ดังนี้:
   - สร้างตารางใน Google Sheets ครบ **8 แท็บ** (`Site_Config`, `Banners_Popups`, `News_Posts`, `Personnel`, `Calendar_Events`, `ITA_Documents`, `Complaints_Inbox`, `Admin_Users`) พร้อมข้อมูลตั้งต้นของโรงเรียนชุมชนแม่ลาศึกษา
   - เชื่อมต่อโฟลเดอร์ Google Drive คลังโรงเรียนโดยตรงตามลิงก์ที่กำหนด: [เปิดโฟลเดอร์ Google Drive คลังโรงเรียน](https://drive.google.com/drive/folders/1SKRLFjJ1HmoVufV8zxNJdtWPBNI6BSfc?usp=sharing) (รหัสโฟลเดอร์: `1SKRLFjJ1HmoVufV8zxNJdtWPBNI6BSfc`) และสร้าง/ตรวจสอบโฟลเดอร์ย่อย 5 โฟลเดอร์ (`01_Banners`, `02_News_Images`, `03_Personnel_Photos`, `04_PDF_Attachments`, `05_ITA_Documents`) พร้อมตั้งค่าสิทธิ์การเข้าถึงไฟล์สาธารณะให้อัตโนมัติ

## ขั้นตอนที่ 2: Deploy เป็น Web App API

1. ในหน้าต่าง Google Apps Script เดิม ให้คลิกปุ่มสีน้ำเงินมุมขวาบน **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกไอคอนรูปเฟืองข้างคำว่า "เลือกประเภท" แล้วเลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `API เว็บไซต์โรงเรียนชุมชนแม่ลาศึกษา v1`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก เพื่อให้หน้าเว็บดึงข่าวสารไปแสดงให้ผู้ปกครองเห็นได้โดยไม่ต้องล็อกอิน)*
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec` เก็บไว้ (ปัจจุบันระบบเชื่อมต่อ URL: `https://script.google.com/macros/s/AKfycbwHiT3_AYUEqyUevcCcRfG87AT9y_VWdwbrZJFVS2eyX6frtoi_3ucaFqeZc5eJ6UEZ/exec`)

## ขั้นตอนที่ 3: เชื่อมต่อ Web App URL เข้ากับ `index.html` และนำขึ้น GitHub Pages

1. เปิดไฟล์ `index.html` บนเบราว์เซอร์ แล้วคลิกปุ่ม **"ระบบผู้ดูแล (Admin)"** ที่มุมขวาบน (หรือเข้าที่ `#/admin`)
2. เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบเริ่มต้น:
   - **อีเมล:** `admin@maela.ac.th`
   - **รหัสผ่าน:** `maela2569`
   *(สามารถเปลี่ยนรหัสผ่านหรือเพิ่มอีเมลครูท่านอื่นได้ในแท็บ `Admin_Users` บน Google Sheets)*
3. ไปที่แท็บ **"ตั้งค่าระบบ & เชื่อมต่อ API"** แล้ววาง **Web App URL** ที่คัดลอกมาจากขั้นตอนที่ 2 ลงในช่อง `Google Apps Script Web App URL` แล้วกด **"บันทึกและทดสอบการเชื่อมต่อ"**
   *(หากต้องการฝัง URL ถาวรลงในโค้ดก่อนอัปโหลดขึ้น GitHub ให้เปิดไฟล์ `index.html` ด้วยโปรแกรมแก้ไขข้อความ ค้นหาตัวแปร `DEFAULT_GAS_WEB_APP_URL` แล้ววาง URL ลงในเครื่องหมายคำพูด)*
4. อัปโหลดไฟล์ `index.html`, `site.webmanifest`, `image-placeholders.js`, `hero-slideshow.js` และโฟลเดอร์ `public/images/` ทั้งโฟลเดอร์ ขึ้นไปยัง Repository บน GitHub ของโรงเรียน โดยรักษาโครงสร้างโฟลเดอร์เดิม แล้วเปิดใช้งาน **Settings > Pages > Deploy from a branch (`main`)** เว็บไซต์ของโรงเรียนชุมชนแม่ลาศึกษาจะพร้อมใช้งานทันที ภาพประกอบ AI จะใช้เมื่อยังไม่มีภาพจริง โดยภาพที่ผู้ดูแลอัปโหลดมีลำดับความสำคัญก่อนเสมอ ดูรายละเอียดใน `docs/IMAGE_GENERATION_GUIDE.md` และชุดโลโก้ใน `docs/SCHOOL_LOGO_GUIDE.md`

## เทคนิคการดูแลรักษาระยะยาว

- **การอัปโหลดรูปกิจกรรม:** เมื่ออัปโหลดรูปภาพผ่านหน้า `#/admin` ระบบจะย่อขนาดรูปภาพด้วย HTML5 Canvas ให้เป็นไฟล์ `.webp` ขนาดไม่เกิน 150–250 KB อัตโนมัติก่อนส่งเข้า Google Drive ช่วยให้พื้นที่ Google Drive 15 GB เก็บรูปกิจกรรมได้มากกว่า 60,000 รูป และหน้าเว็บโหลดเร็วตลอดเวลา
- **การแสดงผลรูปภาพจาก Google Drive:** ระบบแปลงรหัสไฟล์ (`File ID`) เป็นลิงก์ `https://drive.google.com/thumbnail?id=FILE_ID&sz=w1200` โดยอัตโนมัติ จึงไม่ติดปัญหาบล็อกคุกกี้หรือโควตาดาวน์โหลดเต็ม
- **การเปลี่ยนปีการศึกษา:** เมื่อขึ้นปีการศึกษาใหม่ ให้เปลี่ยนค่า `ปีการศึกษาปัจจุบัน` ในหน้า Admin ข่าวสารและเอกสารของปีเก่าจะถูกจัดเก็บเข้าคลังปีการศึกษาเก่าโดยอัตโนมัติ ไม่ต้องลบข้อมูลทิ้ง
