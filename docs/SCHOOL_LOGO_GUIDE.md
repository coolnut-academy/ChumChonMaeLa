# โลโก้โรงเรียน

ต้นฉบับ: `public/LogoSchool.png` (1024×1024, มี alpha โปร่งใสอยู่แล้ว) เก็บไฟล์เดิมไว้ครบถ้วน ชุดโลโก้นี้ส่งออกจากภาพที่ผู้ใช้ให้โดยตรง เพื่อรักษาตัวอักษร สี และรายละเอียดตราเดิม ไม่ได้สร้างตราใหม่ด้วย AI

ตัดเฉพาะพื้นที่ภายนอกที่โปร่งใสทั้งหมดจากต้นฉบับ (left 32, top 24, width 952, height 959) ย่อจากต้นฉบับโดยรักษาสัดส่วน จัดลงพื้นที่สี่เหลี่ยมโปร่งใส ไม่มี padding ตกแต่ง กรอบ เงา glow หรือพื้นสีเพิ่ม รายละเอียดและแสงสะท้อนบนขอบสีทองที่อยู่ในตราเดิมยังคงอยู่

## ไฟล์ที่ใช้งาน

ทั้งหมดอยู่ใน `public/images/branding/`

| ไฟล์ | ขนาด | การใช้งาน |
| --- | --- | --- |
| `school-logo-40.png` / `school-logo-80.png` | 40×40 / 80×80 | ท้ายเว็บ 40px พร้อมภาพสำหรับจอ 2x |
| `school-logo-48.png` / `school-logo-96.png` | 48×48 / 96×96 | ส่วนหัวทุกหน้า 48px (มือถือ 40px) พร้อมภาพสำหรับจอ 2x |
| `school-logo-64.png` / `school-logo-128.png` | 64×64 / 128×128 | หน้าเข้าสู่ระบบ Admin 64px พร้อมภาพสำหรับจอ 2x |
| `favicon.ico` | 16, 32, 48 | ไอคอนแท็บเบราว์เซอร์ |
| `favicon-16x16.png` | 16×16 | favicon PNG |
| `favicon-32x32.png` | 32×32 | favicon PNG |
| `apple-touch-icon.png` | 180×180 | ไอคอนหน้าจอโฮมสำหรับ Apple |
| `android-chrome-192x192.png` | 192×192 | ไอคอนใน web manifest |
| `android-chrome-512x512.png` | 512×512 | ไอคอนขนาดใหญ่ใน web manifest |

ทุกไฟล์เป็น raster โปร่งใส รวมถึงภาพที่บรรจุใน ICO ใช้ path ภายในโปรเจกต์ ไฟล์ `asset-manifest.json` บันทึก SHA-256 ของต้นฉบับ ขอบเขตการตัด และขนาดส่งออก

ขนาดแสดงผลกำหนดตามพื้นที่ UI: ส่วนหัว 48px (มือถือ 40px), ท้ายเว็บ 40px, หน้าเข้าสู่ระบบ 64px แต่ละจุดใช้ไฟล์เท่าขนาดแสดงผลและมี `srcset` ความละเอียด 2 เท่าสำหรับจอ Retina กำหนด width/height ให้ตรงการใช้งานตั้งแต่ HTML จึงไม่ขยายใหญ่ระหว่างรอ CSS โหลด ไฟล์โลโก้ส่วนติดต่อมีขนาดสูงสุด 128×128 และเลิกใช้งานไฟล์ 500×500 แล้ว ไอคอนหน้าจอโฮมยังมีขนาดมาตรฐาน 180/192/512 เพื่อให้เบราว์เซอร์นำไปใช้ได้คมชัด

ใช้ `object-fit: contain` ไม่มีกรอบ พื้นหลัง เงา ฟิลเตอร์ มุมโค้ง หรือ margin/padding บนตัวภาพ และมี alt ภาษาไทย ไฟล์ 1x ส่วนหัวลดจาก 466,849 เหลือ 6,611 bytes

## การส่งออกและนำขึ้นเว็บไซต์

```sh
npm ci
npm run assets:logo
```

คำสั่งอ่าน `public/LogoSchool.png` และส่งออกชุด branding ใหม่โดยไม่เขียนทับต้นฉบับ ไม่มี API หรือบริการภายนอก

นำ `index.html`, `site.webmanifest`, `image-placeholders.js`, `hero-slideshow.js` และ `public/images/` ทั้งโฟลเดอร์ขึ้น hosting พร้อมกัน ใช้ได้กับ GitHub Pages ที่อยู่ใน subdirectory เพราะอ้างอิง relative URL จากหน้าเว็บและ manifest

การเปลี่ยนภาพข่าว/สไลด์/บุคลากรใน Admin ยังคงทำงานตามเดิม โลโก้เป็นไฟล์แบรนด์ของเว็บไซต์และไม่ได้เพิ่มคอลัมน์ฐานข้อมูล
