# สไลด์หน้าแรก 5 ภาพ

ธีมใช้ขาวไข่มุก `#F8FAFD` / `#F1F5FB` และชั้นสีขาวโปร่งโทนเย็น แทนขาวนวลอมน้ำตาล โดยคงสีแดงสตรอว์เบอร์รีและชมพูเดิม

ตามการปรับล่าสุด ชั้นสีขาวฟุ้งจางเป็นโปร่งใสเมื่อถึง 30% ของภาพ: จากด้านซ้ายบน Desktop และจากด้านบนบน Mobile ส่วนที่เหลือแสดงภาพเต็มสี ใช้เงาขาวเฉพาะตัวอักษรช่วยให้ข้อความอ่านได้โดยไม่เพิ่มฟุ้งทั้งภาพ

## การแสดงผล

หน้าแรกมีภาพ AI 5 แบบ: ป้ายโรงเรียน, อาคารประถม, อาคารมัธยม, กิจกรรมหน้าเสาธง และกิจกรรมการเรียนการสอน ดู [ภาพรวม](hero-slides-contact-sheet.webp) ภาพเหล่านี้เป็นสถานที่และบุคคลสมมติ ไม่ใช่ภาพหลักฐานจริง ป้ายโรงเรียนในภาพเว้นว่างโดยตั้งใจ ชื่อโรงเรียนแสดงด้วยข้อความ HTML

สลับแบบ crossfade ทุก **3,000 ms** และวนจากภาพที่ 5 กลับภาพที่ 1 มีลูกศร จุดเลือกภาพ เลขลำดับ และปุ่มหยุด/เล่น หยุดชั่วคราวเมื่อเมาส์อยู่บนสไลด์ เมื่อใช้คีย์บอร์ดจะหยุดจนกดเล่นอีกครั้ง ข้ามการเลื่อนเมื่อแท็บไม่แสดงหรือเปิด modal และไม่เล่นเองเมื่อเครื่องตั้งค่า reduced motion

การเปลี่ยนภาพอัปเดตเฉพาะสไลด์ ไม่ render ข่าวและเนื้อหาหน้าแรกใหม่ทุก 3 วินาที ออกจากหน้าแรกแล้ว clear timer ป้าย AI ปรากฏเฉพาะภาพสำรองหรือเมื่อโหลดภาพจริงไม่ได้

## Admin เปลี่ยนภาพอย่างไร

ดู [ตัวอย่างหน้าจอ Admin](hero-admin-preview.webp)

1. เข้า `#/admin` และเลือกแท็บ **3. แบนเนอร์ & Popup**
2. ด้านบนมี **ภาพสไลด์หน้าแรก 5 ภาพ** แยกเป็นการ์ด 1–5
3. เลือกไฟล์ JPEG/PNG/WebP หรือวาง Google Drive File ID / URL ของภาพ ระบบแสดง Preview ก่อนบันทึก
4. ปรับหัวข้อและคำอธิบายได้ แล้วกด **บันทึกสไลด์นี้**
5. หากต้องการคืนภาพตัวอย่าง กด **ใช้ภาพ AI** แล้วกดบันทึก ใช้เฉพาะกับสไลด์นั้น

เมื่อยังไม่เชื่อมต่อ API ภาพที่เลือกจะย่อเป็น WebP กว้างไม่เกิน 1600px และบันทึกใน localStorage ของเครื่องนี้ เมื่อเชื่อมต่อ API แล้ว ไฟล์ที่เลือกใหม่จะส่งผ่าน `uploadDriveFile` เดิมไปโฟลเดอร์ Banners บน Google Drive และเก็บ File ID ที่ได้รับ หลังบันทึกให้กด **ซิงก์ขึ้น Google Sheets** เพื่อเผยแพร่ record ไปทุกอุปกรณ์

การอัปโหลดไป Drive ใช้ข้อมูลเข้าสู่ระบบที่เก็บเฉพาะในหน่วยความจำของ session ไม่บันทึกรหัสผ่านลง localStorage/backup และล้างเมื่อ logout หาก upload ถูกปฏิเสธหรือผิดพลาด ภาพเดิมไม่ถูกเขียนทับ และ Preview ของภาพที่เลือกยังอยู่ให้ลองบันทึกใหม่ได้

การเปลี่ยนภาพไม่ลบไฟล์เก่าใน Drive และไม่เขียนทับไฟล์ภาพใน repository ภาพจริงมีลำดับความสำคัญก่อนภาพ AI เสมอ การแก้เฉพาะข้อความคงภาพเดิมไว้

## ข้อมูลและการติดตั้ง

ใช้ตาราง `Banners_Popups` และ 13 fields เดิม ไม่มี schema ใหม่ โดยกำหนด default IDs `HERO-ENTRANCE`, `HERO-PRIMARY`, `HERO-SECONDARY`, `HERO-ASSEMBLY`, `HERO-CLASSROOM` ส่วน `imageType`, `slotLabel`, `slotId` เป็น metadata ที่ชั้นแสดงผล ไม่เขียนลง Sheet

ข้อมูลเก่าที่ใช้ `BN-01` / `BN-02` และภาพที่อัปโหลดไว้ยังใช้ได้ เติมตำแหน่งที่ยังไม่ครบด้วย default เฉพาะชั้นแสดงผลโดยไม่ reset ข้อมูลเดิม แบนเนอร์ custom ที่เกิน 5 ภาพยังคงแสดงต่อท้าย ส่วน Popup และแบบฟอร์มจัดการรายการเดิมยังอยู่

`Code.gs` เปลี่ยนเฉพาะ seed ของแบนเนอร์สำหรับ Sheet ที่ยังไม่มีข้อมูลให้มี 5 Hero + 1 Popup เงื่อนไขเดิม `getLastRow() === 1` ยังอยู่ จึงไม่เขียนทับ Sheet ที่ใช้งานแล้ว API upload, authentication และ schema เดิมไม่เปลี่ยน

ต้อง deploy `index.html`, `image-placeholders.js`, **`hero-slideshow.js`** และ `public/images/placeholders/` พร้อมกัน ภาพ Hero ใหม่แต่ละแบบมี main 1200×800 และ thumbnail 480×320 ไม่มี hotlink ของภาพ AI

ดู [ผลตรวจ Desktop/Mobile](FINAL_VERIFICATION.md) การทดสอบ cloud upload ใช้ API จำลองสำเร็จ/ปฏิเสธ ยังไม่ได้ทดสอบกับบัญชี Google จริงหรือ deploy งานนี้
